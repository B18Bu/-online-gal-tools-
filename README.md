# 地球online gal工具包

这是一个 Windows 图形回复助手：它从你校准的微信聊天区域读取最近对话，生成候选回复，并只在你点击候选后复制文本。它不会自动发送消息。

## 使用 EXE

双击 [EarthOnlineGalToolkit.exe](outputs/EarthOnlineGalToolkit.exe) 启动，不会出现终端窗口。

首次使用时：

1. 点击窗口中的“校准区域”。
2. 在 3 秒倒计时内将鼠标移动到微信消息区左上角；随后按提示移动到右下角。
3. 在系统环境变量或与 EXE 同目录的 `.env` 中提供 `DEEPSEEK_API_KEY`。没有时，点击“生成回复”会在窗口中安全提示输入，仅本次使用。
4. 打开微信对应聊天窗口，点击“生成回复”或按 `Ctrl+Alt+J`。
5. 生成完成后，主窗口右侧会显示本次模型判断，包括是否应立刻回答、各动作概率和措辞风险等级。
6. 点击任一候选回复复制，再自行在微信粘贴、检查并手动发送。

生成或校准时可点击“取消”。校准会立即结束；已经发出的生成请求无法由网络层强制撤回，但它返回后会被自动丢弃，不会显示为新的候选结果。

生成时会先显示“正在识别聊天内容”，识别完成后会切换为“已识别消息，正在请求 DeepSeek”。DeepSeek 请求最长等待 45 秒；窗口也会在超时后主动恢复操作并显示错误，即使后台网络线程没有返回。

若生成超时，可点击“检查连接”。它只用当前运行时 Key 发送固定的短 JSON 推理测试，不发送聊天内容，也不显示或写入 Key；检查不会清空已有候选回复。

生成截图时，工具会短暂隐藏自身，避免把窗口里的按钮或状态文字识别成微信消息；识别完成后会立即恢复显示。

关系语气可通过窗口按钮或 `Ctrl+Alt+1` 至 `Ctrl+Alt+5` 切换。窗口内可选“窗口置顶”。

程序只读取 `.env` 内的 `DEEPSEEK_API_KEY`，不会显示、修改或执行其中任何内容。聊天截图默认只在内存中处理；聊天内容会发送给 DeepSeek 生成建议，请自行确认符合你的隐私要求。

“模型判断”中的百分比是模型基于当前 OCR 聊天上下文给出的倾向，用于辅助判断，不是事实或保证。切换关系、开始新一轮生成或生成失败时，上一轮候选和判断会自动失效。

## 源码环境

本机使用 `D:\Python311\python.exe`。首次运行或重新构建前安装依赖：

```powershell
D:\Python311\python.exe -m pip install -r .\requirements.txt
```
## 开发与重打包

源代码在 `earth_online_gal_gui.py` 和 `deepseek_wechat_fallback.py`。在此电脑上可运行：

```powershell
.\build_exe.cmd
```

该命令会重建无终端的 EXE 到 `项目目录\outputs`。主题色、字号和布局可在 `earth_online_gal_gui.py` 的 `EarthOnlineApp` 类中调整。
