# 地球 Online Gal 工具包

一个面向 Windows 微信私聊场景的本地回复建议工具。程序截取你手动校准的聊天区域，通过 RapidOCR 识别最近对话，再调用 DeepSeek 分析上下文并生成最多 3 条候选回复。

> **安全边界：** 本工具不会控制微信输入框，也不会自动发送消息。图形界面中只有在你点击候选回复后，文本才会复制到剪贴板；请自行粘贴、检查并手动发送。

## 核心功能

- **聊天区域 OCR：** 只截取用户校准的微信消息区域，识别左右两侧的聊天文字。
- **DeepSeek 回复建议：** 默认使用 `deepseek-chat`，根据最近对话生成最多 3 条简短候选回复。
- **五种关系模式：** 支持暧昧、同事、家人、客户和好友，分别调整语气、边界与回复倾向。
- **是否回复判断：** 模型会判断当前是否适合立即回答；不建议回复时不会生成可复制的候选内容。
- **行动分析面板：** 显示最佳动作、3 项行动概率、措辞风险等级和模型备注，辅助你判断而不是替你做决定。
- **全局快捷键：** 无需切回工具窗口即可生成回复或切换关系模式。
- **连接检查：** 使用固定的短 JSON 请求检查当前 API Key 和 DeepSeek 连接，不会发送聊天内容。
- **可取消操作：** 校准可立即取消；生成请求取消后，即使后台稍后返回，结果也会被丢弃。
- **隐私优先截图：** 截图默认仅在内存中处理，除非在命令行显式使用 `--debug-screenshot`。
- **窗口置顶：** 可让工具保持在其他窗口上方，便于选择和复制候选回复。

## 工作流程

一次完整生成会依次执行：

1. 工具短暂隐藏自身，避免把按钮、状态文字或候选回复截入图片。
2. 截取已校准的微信聊天区域。
3. RapidOCR 在本机识别截图中的文字。
4. 根据文字位置区分左侧来信和右侧自己的消息，整理最近对话。
5. 将 OCR 后的聊天文本、当前关系模式和回复规则发送给 DeepSeek。
6. 显示是否应回复、最佳动作、行动概率、措辞风险和候选回复。
7. 你点击候选内容，将其复制到剪贴板，再自行粘贴并发送。

正常生成请求最长等待 **45 秒**。连接检查最长等待 **15 秒**。

## 快速开始（EXE）

### 1. 准备程序

推荐使用构建输出：

```text
outputs\EarthOnlineGalToolkit.exe
```

双击运行后不会出现命令行窗口。首次启动建议将 EXE、`.env` 和配置文件放在同一目录。

### 2. 配置 DeepSeek API Key

在 EXE 同目录新建 `.env` 文件：

```dotenv
DEEPSEEK_API_KEY=你的_DeepSeek_API_Key
```

也可以复制仓库中的 `.env.example` 并重命名为 `.env`，然后替换示例值。

配置规则：

- 程序优先读取系统环境变量 `DEEPSEEK_API_KEY`。
- 未设置环境变量时，读取程序同目录 `.env` 中的同名配置。
- 图形界面仍未找到 Key 时，会提示输入；该值仅供当前运行使用，不会自动写入文件。
- 程序只读取 `.env` 中的 `DEEPSEEK_API_KEY`，不会执行、显示或修改其他内容。
- 不要提交包含真实 Key 的 `.env`，也不要通过截图或聊天发送给他人。

### 3. 校准微信聊天区域

1. 打开微信并进入目标私聊。
2. 在工具中点击 **“校准区域”**。
3. 按倒计时提示，将鼠标移动到消息区域的左上角。
4. 再按提示移动到消息区域的右下角。
5. 完成后，坐标会保存到 `earth_online_gal_config.json`。

建议只框选中间的**消息气泡区域**：

- 包含左侧对方消息和右侧自己的消息。
- 不要包含微信左侧会话列表、顶部标题、输入框和工具栏。
- 尽量不要包含图片、表情面板或其他浮层。
- 对方消息必须位于截图左半侧；工具会依据横向位置判断消息来源。

配置文件格式如下，四个数字依次为左边距、上边距、宽度和高度：

```json
{
  "chat_region": [
    0,
    0,
    800,
    600
  ]
}
```

上面的数字仅是格式示例，请使用校准功能生成适合自己屏幕缩放和微信窗口位置的坐标。

### 4. 生成并使用回复

1. 保持目标微信聊天可见，确认没有菜单或其他窗口遮挡消息区域。
2. 在工具中选择关系模式。
3. 点击 **“生成回复”**，或按 `Ctrl+Alt+J`。
4. 等待状态从“正在识别聊天内容”切换为“已识别消息，正在请求 DeepSeek”。
5. 查看模型判断与最多 3 条候选回复。
6. 点击合适的候选，将文字复制到剪贴板。
7. 返回微信粘贴，检查语气、事实和称呼后手动发送。

如果模型判断当前不适合回复，界面会给出说明而不会提供候选文本。

## 界面说明

### 操作按钮

| 按钮 | 作用 |
| --- | --- |
| 生成回复 | 截图、OCR、请求 DeepSeek 并刷新候选结果 |
| 取消 | 取消当前校准或使本轮生成结果失效 |
| 检查连接 | 用固定短请求检查 API Key 和网络，不发送聊天内容 |
| 校准区域 | 重新选取微信消息区域并保存配置 |
| 窗口置顶 | 切换主窗口是否保持在其他窗口上方 |

生成、切换关系、取消或发生错误时，上一轮不再适用的候选和判断会被清除，避免误用旧结果。

### 模型判断

右侧“模型判断”区域包含：

- **是否应该立即回答：** `Yes` 或 `No`，表示模型根据当前 OCR 上下文给出的回复倾向。
- **最佳动作：** 模型认为当前最适合采取的操作，例如直接回答、先澄清或暂缓回复。
- **行动概率：** 展示 3 个可能动作及其相对概率。
- **措辞风险：** `1–10` 级；数值越高，越需要检查语气、关系边界和可能引起误解的表达。
- **模型备注：** 对判断原因或需要注意事项的简短补充。

这些结果是语言模型基于有限聊天文本生成的建议，不是事实、承诺或可靠的人际关系判断。涉及工作承诺、金额、时间、隐私和敏感关系时，请以自己的核实结果为准。

## 关系模式与快捷键

| 快捷键 | 关系模式 / 操作 | 适用语气 |
| --- | --- | --- |
| `Ctrl+Alt+J` | 识别聊天并生成候选回复 | 使用当前关系模式 |
| `Ctrl+Alt+1` | 暧昧 | 自然、有分寸，不过度讨好或冷淡 |
| `Ctrl+Alt+2` | 同事 | 工作优先，礼貌、专业、减少私人闲聊 |
| `Ctrl+Alt+3` | 家人 | 亲近但保留边界，兼顾长辈问话 |
| `Ctrl+Alt+4` | 客户 | 服务导向、专业、高效 |
| `Ctrl+Alt+5` | 好友 | 更适合接梗、吐槽和熟人式表达 |

快捷键是全局注册的。如果快捷键无反应，请先确认程序仍在运行，并检查是否被其他软件占用或被安全软件拦截。

## 隐私与数据处理

使用前请了解以下边界：

- 微信截图默认只在内存中处理，不会自动保存到磁盘。
- 只有命令行显式传入 `--debug-screenshot PATH` 时，截图才会保存到指定路径。
- OCR 在本机完成，但 OCR 后的聊天文字会发送给 DeepSeek 以生成建议。
- “检查连接”只发送固定测试内容，不发送微信聊天文本。
- API Key 用于调用 DeepSeek；程序不会在界面中展示或写回 Key。
- 工具不会自动操作微信输入框，也不会自动发送任何消息。
- 如果聊天包含身份证号、账号、合同、客户资料或其他敏感信息，请先确认使用第三方模型符合你的隐私和合规要求。

## 常见问题

### 提示未检测到 `DEEPSEEK_API_KEY`

- 确认文件名是 `.env`，而不是 `.env.txt`。
- 确认 `.env` 与实际运行的 EXE 位于同一目录。
- 确认配置写成 `DEEPSEEK_API_KEY=...`，等号两侧不要使用全角符号。
- 也可以在系统环境变量中设置同名变量后重新启动程序。

### 点击生成后提示网络错误或 45 秒未响应

1. 点击 **“检查连接”**。
2. 检查 API Key 是否有效、是否有可用额度。
3. 检查网络、代理、防火墙或安全软件是否允许程序访问 DeepSeek。
4. 稍后重试；连接检查只验证固定短请求，不代表长上下文请求一定成功。

### 提示未配置聊天区域

点击 **“校准区域”** 完成一次校准。移动微信窗口、更改显示器、调整系统缩放或修改微信窗口大小后，建议重新校准。

### 提示没有识别到左侧最新来信

- 确认截图范围内确实有对方发来的文字消息。
- 缩小校准范围，只保留消息气泡区域。
- 避免让图片、表情、弹窗或工具窗口遮挡聊天内容。
- 确认对方消息位于校准区域左半侧。
- OCR 更适合清晰文字；过小字号、低对比度和纯图片内容可能无法识别。

### OCR 识别内容不完整或串行

- 放大微信窗口或适当提高消息字号。
- 保持聊天区清晰，避免半透明窗口覆盖。
- 重新校准，减少无关界面元素。
- 如需定位问题，可在命令行使用 `--debug-screenshot` 保存本次截图，但调试完成后应及时删除含聊天内容的图片。

### 全局快捷键无反应

- 先使用界面按钮确认程序本身可以正常生成。
- 检查 `Ctrl+Alt+J` 或数字组合是否被输入法、显卡工具、远程软件等占用。
- 某些环境下可能需要以相同权限级别运行工具和微信。
- 源码命令行模式还需要正确安装 `keyboard` 依赖。

### 点击候选后无法粘贴

- 再次点击候选，观察状态栏是否提示复制成功。
- 检查剪贴板管理器或安全软件是否阻止程序写入剪贴板。
- 在记事本中测试粘贴，确认是否为微信自身焦点问题。

### 点击“取消”后为什么网络请求似乎仍在后台运行

已经发出的网络请求不一定能被底层连接立即终止。工具会立刻恢复界面并将本轮任务标记为取消；后台结果即使稍后返回，也不会更新候选回复。

## 开发者附录

### 运行环境

项目面向 Windows，当前批处理脚本默认使用：

```text
D:\Python311\python.exe
```

如果本机 Python 不在该位置，请修改 `run_toolkit.cmd` 和 `build_exe.cmd` 中的 `PYTHON_EXE`，或直接使用自己的 Python 命令执行后续步骤。

安装依赖：

```powershell
D:\Python311\python.exe -m pip install -r .\requirements.txt
```

### 运行图形界面

```powershell
D:\Python311\python.exe .\earth_online_gal_gui.py
```

GUI 支持候选按钮、模型判断、连接检查、取消操作、区域校准和窗口置顶，是普通用户推荐的入口。

### 运行命令行版本

```powershell
.\run_toolkit.cmd
```

命令行模式运行后：

- 按 `Ctrl+Alt+J` 触发识别与生成。
- 按 `Ctrl+Alt+1` 至 `Ctrl+Alt+5` 切换关系。
- 如果建议回复，第一条候选会自动复制到剪贴板，但仍不会自动粘贴或发送。
- 按 `Ctrl+C` 退出。

可用参数：

```text
--calibrate
--region LEFT TOP WIDTH HEIGHT
--model MODEL_NAME
--debug-screenshot PATH
```

示例：

```powershell
# 交互式校准并保存聊天区域
.\run_toolkit.cmd --calibrate

# 仅本次使用指定区域，不修改已保存配置
.\run_toolkit.cmd --region 0 0 800 600

# 指定模型
.\run_toolkit.cmd --model deepseek-chat

# 保存调试截图；文件可能包含聊天隐私
.\run_toolkit.cmd --debug-screenshot .\debug-chat.png
```

### 运行测试

```powershell
D:\Python311\python.exe -m unittest -v .\test_earth_online_gal_toolkit.py
```

测试覆盖 OCR 结果整理、DeepSeek 返回格式规范化、回复判断、行动概率、风险等级、`.env` 安全读取等核心逻辑。

### 构建 EXE

```powershell
.\build_exe.cmd
```

构建脚本使用 PyInstaller 生成无终端窗口的单文件程序：

```text
outputs\EarthOnlineGalToolkit.exe
```

## 使用提醒

候选回复只是草稿。发送前请检查人物称呼、事实、日期、金额、承诺和情绪表达；不要把模型概率当成对方真实意图，也不要让工具代替必要的直接沟通。
